# mi-primer-pr

Este repositorio es una práctica para aprender a abrir Pull Requests en GitHub.

## ¿Qué es un Pull Request?

Un Pull Request (PR) es una propuesta de cambio en un repositorio. Permite revisar el código antes de fusionarlo con la rama principal.

## Pasos seguidos

1. Crear el repositorio en GitHub
2. Clonar el repositorio localmente
3. Crear una rama nueva
4. Hacer un cambio
5. Abrir un Pull Request
